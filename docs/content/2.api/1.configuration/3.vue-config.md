Una UI can also be used in a plain Vue application.

1. Install the `@una-ui/components` package.

```sh
pnpm add @una-ui/components
```

2. Add the plugin to your app.

```js
import UnaUI from '@una-ui/components/plugin'
import { createApp } from 'vue'

const app = createApp()
app.use(UnaUI, {/* una-ui config goes here */})
app.mount('#app')
```
